# Lab — Module 08: Data for AI

## Designing a document base ready for RAG

Practice organizing, classifying and preparing data before the generation stage.

## Prerequisites

- Read the module.
- Separate a fictitious set of documents.

## Steps

1. Create document categories by area, date and sensitivity.
2. Define naming convention and versioning.
3. List useful metadata for future retrieval.
4. Mark which documents need to be deleted, masked or approved before use.
5. Design the base's periodic update flow.

## What to observe

- The organization of the database directly influences the retrieval quality.
- Data governance starts before the model.

## Costs and cleanup

- Lab with no mandatory cost.
- In a real environment, validate retention and access policies before connecting data to AI.
