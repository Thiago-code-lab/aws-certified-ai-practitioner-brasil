# Cheatsheet — Module 08: Data for AI

> Quick review designed for the final review of the AWS Certified AI Practitioner exam.

## At a glance

| Topic | What to remember | Exam trap |
| --- | --- | --- |
| S3 | Common origin of data and documents. | It is not complete governance alone. |
| Chunking | Splits documents into useful parts for retrieval. | Bad chunks reduce RAG accuracy. |
| Macie | Discover sensitive data in S3. | Does not replace access policies. |
| Lake Formation | Data lake governance. | It is not an AI generation service. |

## Practical rules

- Version relevant documents and datasets.
- Remove or isolate content that is obsolete, duplicated, or too sensitive for the use case.
- Use metadata to facilitate filtering and governance.
- Classify data before connecting it to AI applications.

## Memory cues

- A curated knowledge base supports better answers; poor source data can spread errors faster.
- Uncurated documents can provide misleading context.
- S3 stores; metadata guides; governance protects.
