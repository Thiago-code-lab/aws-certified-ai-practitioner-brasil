## Overview

Prepare for **AWS Certified AI Practitioner (AIF-C01)** through 18 modules covering AI, machine learning, generative AI, and their business applications on AWS. Learn to choose services, evaluate model outputs, protect data, and apply responsible AI principles through detailed lessons, examples, flashcards, cheatsheets, guided labs, and practice questions.

These MIT-licensed learning materials are free. CloudStudy's platform and linked courses may have separate terms. Original project artwork is preserved and may contain Portuguese text.

## Recommended learning roadmap

1. **Modules 01–05:** AI and ML fundamentals, generative AI, foundation models, LLMs, embeddings, RAG, and Amazon Bedrock.
2. **Modules 06–10:** Amazon SageMaker AI, responsible AI, governance, data preparation, prompt engineering, and generative application design.
3. **Modules 11–15:** Security, compliance, use cases, AWS AI services, application integration, cost, latency, and quality optimization.
4. **Modules 16–18:** Practice exams, error analysis, final review, glossary, and official learning resources.

Read each lesson, answer its questions, and use the expandable flashcards for spaced repetition. Review the cheatsheet and complete the lab before moving on. Labs include conceptual architecture exercises and optional AWS exploration; read cost and cleanup instructions before provisioning resources.

## AWS AI and generative AI topics

- **AI and ML:** Supervised, unsupervised, and reinforcement learning; classification, regression, clustering, training, inference, evaluation, and generalization.
- **Generative AI:** Foundation models, LLMs, tokens, context windows, embeddings, vector databases, RAG, fine-tuning, prompting, and hallucination mitigation.
- **AWS services:** Amazon Bedrock, Amazon SageMaker AI, Amazon Q, Textract, Comprehend, Rekognition, Transcribe, Translate, Polly, Lex, and Personalize.
- **Responsible operation:** Fairness, explainability, human review, IAM, encryption, secrets, audit trails, privacy, monitoring, and cost control.

## Practice exams and final review

- [Question bank](16-Practice-Exams-and-Questions/questions.md): six multiple-choice questions with explanations.
- [Full Practice Exam 1](16-Practice-Exams-and-Questions/full-practice-exam-1.md): eight questions.
- [Full Practice Exam 2](16-Practice-Exams-and-Questions/full-practice-exam-2.md): eight questions, repeating the first set as in the source.
- [Domain practice](16-Practice-Exams-and-Questions/domain-practice-exams.md): eight questions; see the [domain inventory](docs/english-edition/question-audit.json) for classifications.
- [Final review](16-Practice-Exams-and-Questions/final-review-aif-c01.md): 14-day and 7-day plans.
- [Error log](16-Practice-Exams-and-Questions/error-log.md), [exam cheatsheet](16-Practice-Exams-and-Questions/cheatsheet.md), and [glossary](17-Glossary/README.md).

The source contains **30 multiple-choice occurrences (22 distinct questions)**, **85 short-answer review prompts**, and **144 flashcards**. Despite the inherited “Full Practice Exam” filenames, the two eight-question sets are short exercises. They do not constitute a full-length 65-question mock exam. No questions have been added or removed.

## Official AWS references

The 18 modules form a learning sequence; the certification has five official domains. Consult the [AWS exam guide](https://docs.aws.amazon.com/aws-certification/latest/ai-practitioner-01/ai-practitioner-01.html), [in-scope services](https://docs.aws.amazon.com/aws-certification/latest/ai-practitioner-01/aif-01-in-scope-services.html), and [certification page](https://aws.amazon.com/certification/certified-ai-practitioner/) before scheduling the exam.

| Official domain | Weight |
| --- | ---: |
| 1. Fundamentals of AI and ML | 20% |
| 2. Fundamentals of GenAI | 24% |
| 3. Applications of Foundation Models | 28% |
| 4. Guidelines for Responsible AI | 14% |
| 5. Security, Compliance, and Governance for AI Solutions | 14% |

References were checked on November 16, 2026. The [revision history](https://docs.aws.amazon.com/aws-certification/latest/ai-practitioner-01/aif-01-revisions.html) lists exam guide version 1.2, published October 29, 2026. This edition translates the complete source curriculum; consult the current guide for newer agentic AI topics and service changes beyond that source scope. Start hands-on learning with [AWS Skill Builder](https://skillbuilder.aws/), and consult [Bedrock documentation](https://docs.aws.amazon.com/bedrock/latest/userguide/what-is-bedrock.html) and [SageMaker AI documentation](https://docs.aws.amazon.com/sagemaker/latest/dg/whatis.html) for service details.
