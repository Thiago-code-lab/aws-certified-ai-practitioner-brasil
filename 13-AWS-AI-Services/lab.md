# Lab — Module 13: AWS AI Services

## Memorization by service families

Group services by problem solved to speed up reading exam questions.

## Prerequisites

- Read the module and the official list in scope.

## Steps

1. Create columns: voice, document, vision, NLP, recommendation, productivity, GenAI.
2. Place each service in the correct family.
3. Write a quick use case for each service.
4. Mark which services are specialized and which are platforms.
5. Review the most confusing pairings: Comprehend vs Bedrock, Textract vs LLM, Personalize vs search.

## What to observe

- Memorization becomes stronger when associated with a solved problem.
- Most of the wrong alternatives exploit similar family services.
