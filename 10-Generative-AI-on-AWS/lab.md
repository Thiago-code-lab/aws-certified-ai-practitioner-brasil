# Lab — Module 10: Generative AI on AWS

## Architecting a serverless GenAI application

Build a minimum viable AWS architecture for a corporate assistant.

## Prerequisites

- Know Bedrock, S3, API Gateway and Lambda at a conceptual level.

## Steps

1. Design the user flow -> API -> backend -> model -> response.
2. Decide where documents, logs and access policy are located.
3. Mark which calls are synchronous and which would be asynchronous.
4. Include a fallback for error or low confidence.
5. Explain how to monitor cost and latency.

## What to observe

- A good GenAI architecture needs layers beyond the model.
- Security and observability appear from the first diagram.

## Costs and cleanup

- No mandatory cost if done only on the diagram.
- If you run a real proof of concept, remove unused resources.
