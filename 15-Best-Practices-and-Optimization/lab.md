# Lab — Module 15: Best Practices and Optimization

## Optimization checklist for an AI application

Evaluate where an application can save money without losing relevant quality.

## Prerequisites

- Read the module.

## Steps

1. Choose a use case with frequent model calls.
2. List call volume, context size and response type.
3. Ask if there is a chance of using cache, batch, smaller model or leaner context.
4. Define which metrics you would monitor in CloudWatch.
5. Create a conceptual cost alert with AWS Budgets.

## What to observe

- The best optimization usually combines more than one lever.
- Cost and quality must be measured together.
