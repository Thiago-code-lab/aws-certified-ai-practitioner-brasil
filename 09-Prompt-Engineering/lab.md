# Lab — Module 09: Prompt Engineering

## Refining an operational prompt

Transform a generic prompt into a prompt ready for use in a real application.

## Prerequisites

- Read the module.
- Have a simple case of text to classify or summarize.

## Steps

1. Write a short, generic opening prompt.
2. Add role, objective, context and output format.
3. Include one or two examples of an ideal answer.
4. Set constraints: do not invent facts, respond in English, and state when context is insufficient.
5. Compare your answers and record your progress.

## What to observe

- Small instruction changes can greatly alter the output.
- Good operational prompts are often more explicit than creative prompts.

## Costs and cleanup

- No mandatory cost if done conceptually only.
- If you use real services, do not leave unnecessary resources active.
