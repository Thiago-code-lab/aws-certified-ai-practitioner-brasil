# Cheatsheet — Module 09: Prompt Engineering

> Quick review designed for the final review of the AWS Certified AI Practitioner exam.

## At a glance

| Topic | What to remember | Exam trap |
| --- | --- | --- |
| Role prompt | Defines the expected role of the model. | It’s not enough on its own without context. |
| Few shot | Uses examples to guide pattern. | It's not model training. |
| Structured output | Important for integration with systems. | Free text makes automation difficult. |
| Versioning | It helps to compare and control changes. | Changing the prompt can alter production. |

## Practical rules

- Describe the role, objective, context, format and limits of the response.
- Use few-shot when the task requires consistency of style or structure.
- Ask for verifiable formats, such as JSON or numbered lists, when integration depends on it.
- Avoid excessive and irrelevant context.

## Memory cues

- Good prompt reduces ambiguity.
- Example teaches pattern without re-training.
- Explicit format protects integrations.
