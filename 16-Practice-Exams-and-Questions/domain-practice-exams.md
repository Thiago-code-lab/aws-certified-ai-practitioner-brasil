## Question 17

**Question:** In a question that contrasts RAG and fine-tuning for dynamic document bases, the best choice tends to be:

- A) Recurrent fine-tuning
- B) Vector-based RAG
- C) No context source
- D) Fixed single prompt

<details>
<summary><strong>See answer</strong></summary>

✅ **Correct answer:** B

**Explanation:**
RAG favors continuous updating of knowledge without frequent retraining.

**Why option A is wrong:**
Frequent fine-tuning adds training cost and delays document updates when retrieval would meet the requirement.

</details>

## Question 19

**Question:** To provide an API secret to your application with the lowest risk, you should:

- A) Embed it in the code
- B) Store it in Secrets Manager
- C) Save it in an unprotected local variable
- D) Publish to public S3

<details><summary><strong>See answer</strong></summary>

✅ **Correct answer:** B

**Explanation:**
Secrets Manager centralizes control, rotation, and secure access to secrets.

**Why option A is wrong:**
Hardcoding secrets compromises security and governance.

</details>
