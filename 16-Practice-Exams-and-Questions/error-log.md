# Error Log — AIF-C01

Use this file after each simulation. The goal is not just to record the right alternative, but to understand why your logic failed.

## Classify the error before correcting it

| Error type | How to recognize |
| --- | --- |
| Concept error | You didn't understand the term or confused definitions |
| Service error | You knew the problem, but you chose the wrong AWS service |
| Reading error | The statement contained a key detail and you ignored it |
| Governance error | You underestimated security, auditing, human review, or policy |
| Cost/latency error | You chose a working but not optimized solution |

## How to use

1. Fill out the template immediately after completing a practice exam.
2. Group errors by pattern: Bedrock vs SageMaker, security, RAG, cost, governance.
3. Redo only the questions you got wrong after reviewing.
4. Rewrite the rule of thumb in your own voice. This reinforces learning more effectively than simply rereading the answer key.

## Useful questions to reflect on

- Did I make a mistake because I didn't know the concept or because I read it too quickly?
- Was the correct alternative better managed, safer or simpler?
- Did the statement ask for generation, classification, extraction, recommendation or governance?
- If this same logic reappears, what short sentence will help me get it right?
