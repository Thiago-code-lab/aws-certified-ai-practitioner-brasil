# Lab — Module 14: Integration with Applications

## Choosing the right integration pattern

Practice deciding between synchronous, asynchronous, and event-driven.

## Prerequisites

- Know Lambda, API Gateway, SQS and EventBridge conceptually.

## Steps

1. Write three cases: chatbot, contract processing and registration enrichment.
2. Choose the main integration pattern for each one.
3. Note expected latency, required resilience, and operational cost.
4. Define where observability enters the design.
5. Review whether the chosen pattern matches the user experience.

## What to observe

- The same model can be used in different integrations, depending on the case.
- The right architecture depends on the expected behavior of the flow.

## Costs and cleanup

- Conceptual lab, with no mandatory cost.
