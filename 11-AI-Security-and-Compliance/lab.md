# Lab — Module 11: AI Security and Compliance

## Security checklist for a GenAI application

Map out minimum security controls before releasing a generative application.

## Prerequisites

- Read the module and have a use case in mind.

## Steps

1. List what data goes into the model and if any is sensitive.
2. Define who can access documents, prompts, logs and outputs.
3. Choose how to keep secrets and how to log audits.
4. Separate controls by environment: dev, test and production.
5. Note which risks still require additional human or policy review.

## What to observe

- AI security is a composition of controls.
- Shared responsibility remains valid in any managed service.

## Costs and cleanup

- Lab with no mandatory cost.
- In real POCs, do not use sensitive data without formal approval.
