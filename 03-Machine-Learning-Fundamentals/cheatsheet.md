# Cheatsheet — Module 03: Machine Learning Fundamentals

> Quick review designed for the final review of the AWS Certified AI Practitioner exam.

## At a glance

| Topic | What to remember | Exam trap |
| --- | --- | --- |
| Classification | Provides a category, such as fraud or non-fraud. | Not to be confused with cluster. |
| Regression | Predicts continuous numeric value. | It's not for class label. |
| Clustering | Groups unlabeled patterns. | Does not respond directly to a known target. |
| Ground Truth | Data labeling for supervised training. | It is not a core inference service. |

## Practical rules

- Confirm whether the problem is classification, regression or clustering before choosing the technique.
- Separate training, validation and testing to measure generalization.
- Take care of the quality of labels and the consistency of the dataset.
- Choose metrics consistent with the business, not just accuracy.

## Memory cues

- Label present? think supervised.
- No ready answer? think pattern discovery.
- Good training is not enough; Testing is the reality filter.
