# Lab — Module 03: Machine Learning Fundamentals

## Identifying the right type of ML problem

Practice interpreting business problems to correctly map the main ML technique.

## Prerequisites

- Read the module's README.
- Gather business examples from your own context.

## Steps

1. Write three problems: a prediction problem, a continuous value problem, and a clustering problem.
2. Mark for each one whether the desired output is class, number or group.
3. Associate classification, regression or clustering.
4. List what data would be needed and if there are labels.
5. Review whether any case could be solved by ready-made service instead of custom ML.

## What to observe

- Most errors in testing arise from misreading the business objective.
- Available label is a great flag for supervised learning.
