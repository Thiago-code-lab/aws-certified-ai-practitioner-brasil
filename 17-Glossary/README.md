## Essential Glossary

| Term | Full name | Practical definition |
| --- | --- | --- |
| A2I | Amazon Augmented AI | Selective human review in AI workflows. |
| Bedrock | Amazon Bedrock | Managed service for consuming foundation models. |
| Chunking | Document division | Separation of documents into smaller parts for retrieval. |
| Embedding | Vector representation | Conversion of content into vector for semantic search. |
| Few shot | Prompt with examples | Prompt technique that uses input and output examples. |
| Fine-tuning | Model adjustment | Adapting model behavior with additional data. |
| FM | Foundation Model | Reusable base model for multiple tasks. |
| Grounding | Anchoring in context | Use of reliable sources to support the model response. |
| Guardrails | Policy Controls | Mechanisms to restrict and protect AI interactions. |
| Hallucination | Hallucination | Plausible answer, but incorrect or invented. |
| Inference | Inference | Using the trained model to respond to new inputs. |
| Knowledge Base | Knowledge Base | Document source connected to the model for grounding. |
| LLM | Large Language Model | Foundation model focused on natural language. |
| PII | Personally Identifiable Information | Identifiable personal data. |
| Prompt engineering | Prompt engineering | Structuring instructions and context to guide output. |
| RAG | Retrieval-Augmented Generation | Context retrieval followed by generation. |
| SageMaker AI | ML Platform | End-to-end service for ML workflows. |
| Token | Processing unit | A unit produced by tokenization, such as a word fragment or character sequence; text models process input and output in tokens rather than assuming one token per word. |
| Training | Training | Phase in which the model learns from data. |
| Vector database | Vector database | Stores embeddings and allows similarity search. |

## Review tips

- GenAI terms often appear mixed in the same question: prompt, grounding, RAG, embedding and vector database.
- Classic confusions: Bedrock vs SageMaker AI, embedding vs generation, RAG vs fine-tuning, Guardrails vs IAM.
- Use [flashcards](./flashcards.md) for active review.
