# Guided Review - Essential Glossary

## Quick Review (Q&A)

- **Quick question:** Embedding?
  **Short answer:** Vector representation.
- **Quick question:** RAG?
  **Short answer:** Retrieval + generation.
- **Quick question:** Fine-tuning?
  **Short answer:** Specialization.
- **Quick question:** Injection?
  **Short answer:** Prompt attack.
- **Quick question:** Drift?
  **Short answer:** Change in data.
