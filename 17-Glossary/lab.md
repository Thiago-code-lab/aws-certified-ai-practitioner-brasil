# Lab — Glossary

## Active review in 20 minutes

1. Read 10 terms from the glossary without looking at the definition.
2. Try to explain each term out loud or in writing.
3. Check the study definition in the README and correct anything that is incomplete.
4. Mark which terms still cause confusion.
5. Return to the corresponding thematic module.
